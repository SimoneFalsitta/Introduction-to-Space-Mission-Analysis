# Introduction to Space Mission Analysis

## Overview
This MATLAB project focuses on calculating and analyzing orbital transfer trajectories around the Earth from a specific initial position to a target position. It evaluates key mission parameters, including delta-v (impulse) requirements and flight time trade-offs, to determine optimal transfer maneuvers.

## Key Features
- **3D Trajectory Simulations**: Visualization of transfer orbits and spatial maneuvers.
- **Trade-Off Analysis**: Cost-benefit evaluation between impulse expenditure and time-of-flight (scatterplot analysis).
- **Parametric Orbit Calculation**: Automated determination of transfer orbit parameters.

## Repository Content
- `ProvaFinale.m`: Main MATLAB script used for simulation, trajectory calculation, and plotting.
- `Report Prova Finale IAMS_240105_190358.pdf`: Complete technical report detailing the mathematical formulation and results.

## Requirements & Usage
- **Software**: MATLAB 
- **Execution**:
  1. Open MATLAB and navigate to the repository directory.
  2. Run `ProvaFinale.m` to start the trajectory simulation and generate performance graphs.
